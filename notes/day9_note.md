 ## Python Function Concept

def คือคำสั่งที่ใช้สร้างฟังก์ชันใน Python เพื่อรวมโค้ดไว้ใช้งานซ้ำได้

parameter คือค่าที่ส่งเข้าไปในฟังก์ชันเพื่อให้ฟังก์ชันนำไปใช้คำนวณ

return คือคำสั่งที่ใช้ส่งค่ากลับออกมาจากฟังก์ชัน

print() ใช้แค่แสดงผลออกหน้าจอ แต่ return จะส่งค่ากลับไปใช้ต่อในโปรแกรมได้
