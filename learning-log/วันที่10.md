วันนี้จบคอร์สไป 4 ตัวได้แก่ Google Colab [Fundamental] ,Introduction to Data Visualization [Fundamental],AI Ethics [Fundamental],GitHub [Fundamental]

คอร์สไหนผมรู้พื้นฐานอยู่แล้วคือ : Google Colab [Fundamental] เพราะว่าที่มหาลัยส่วนใหญ่ก็จะเป็นการสอนพวก Colab อยู่้แล้ว และได้ทำโปรเจคที่อยู่รายวิชาผ่านตัวนี้เป็นส่วนใหญ่ และ Introduction to Data Visualization ด้วยความที่เรียนสาขา Data science ก็จะคุ้นเคยอยู่แล้ว แต่จะเป็นในระดับพื้นฐานในห้องเรียนเฉยๆ

คอร์สไหนยังต้องกลับมาทบทวนคือ : GitHub [Fundamental] เพราะว่าเรายังไม่ค่อยเข้าใจคำสั่ง หลายๆคำสั่ง เช่น git commit , git push ,การ branch แต่ก็มีบางอันที่เราเข้าใจ เพราะว่ามีบางอันที่เราคยเรียนในวิชา Hadoop แล้วการสร้าง comman ต่างๆเช่น การใช้ mkdir , cd, add,การ swicth เป็นต้น

วันนี้ได้อะไรที่ใช้ต่อได้จริง : อย่างแรกเลยการเรียน Colab มันมีบางสิ่งที่เราไม่รู้เช่นการ Fromเป็นต้น เราก็พึ่งมารู็ว่ามันสร้างได้และปรับแต่งได้ ส่วน วิชาที่เรียน Data Visualization เราเข้าใจว่ากราฟแต่ละประเภทอันไหนได้ใช้จริงๆและกราหรือการแสดงผลแบบไหน มันเหมาะกับข้อมูลแบบไหนจริงๆ และเราเอาสิ่งอาจาร์ยสอนตรงนรี้ไปใช้ได้การแสดงกราฟที่ดีคือไม่ควรเยอะไป ควรแสดงง่ายๆตรงประเด็นเป็น และ AI Ethics [Fundamental] เรารู้ว่าปัญญาประดิษฐ์ มีขอบตอะไรบ้างกระบวนการแบบไหน เช่น ฝั่ง ก็จะมีกฎ 26 ข้อเป็นต้น หรือขั้นตอนที่ใช้ดู ก็มี 3 ขั้นตอนหลักๆ ให้เราดูและทำประมาณนี้ ตจรงนี้เราสามารถเอาไปใช้ต่อในคอร์ส AI วิชาอื่นๆได้ สุดท้าย GitHub [Fundamental] เรารู้ว่าแต่ละตัวมันใช้ยังไง เช่นการสร้าง การเพิ่ม การใช้เชื่อมกับ VS code และการเชื่อมกับ git ตรงนี้จะช่วยให้เราเวลาทำงานเป็นทีมจะรู้และง่าย เช่น ผมทำ model อีกคน UI อีกคน dev พอถึงการทำงานเป็นทีม ตรงนี้จะสะดวกสุดๆ และเป็นระเบียบ

พรุ่งนี้จะเริ่มอะไร : พรุ่งนี้จะเริ่มเรียนวิชาต่อไป ให้ได้ ประมาณ 4 วิชา เช่น ML และฝึกทำ ML ก่อนไปเรียนตอนที่ไปเรียนจะได้เข้าใจมากขึ้น และ นำสิ่งที่เรียนออกมาใช้ จะเริ่มทำโปรเจคระดับกลาง หา data set มาทำ และฝึกในสิ่งที่ขากอีก และพร้อมจะเรียนตอนเย็น ในส่วนของ model
